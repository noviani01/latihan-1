# Kalkulator Umur

Aplikasi web sederhana untuk menghitung umur dalam tahun, bulan, dan hari,
serta menampilkan zodiak Barat dan informasi Pawukon Bali (saptawara,
pancawara, dan wuku) berdasarkan tanggal lahir.

## Menjalankan

Buka `index.html` di browser, pilih tanggal lahir, lalu tekan **Hitung umur**.
Perhitungan zodiak hanya menggunakan tanggal, sedangkan informasi Pawukon
menampilkan siklus wewaran dan wuku, bukan kalender Saka atau sasih.
